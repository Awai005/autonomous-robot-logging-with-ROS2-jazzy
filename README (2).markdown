### ROS Bags, Visualization, and Future Goals

- **ROS Bags**: The experiment data is recorded in ROS bags stored in the `rosbags/` directory. These bags capture the `/waypoint_status` topic (containing waypoint positions, timestamps, and status messages like "Reached waypoint 1"), `/odom` (robot odometry), `/tf` (transformations), and `/navigate_to_pose/goal` and `/navigate_to_pose/result` (navigation goals and results). Record bags with:
  ```bash
  ros2 bag record /waypoint_status /odom /tf /navigate_to_pose/goal /navigate_to_pose/result
  ```

- **Screen Recording**: A screen recording (`docs/navigation_recording.mp4`) demonstrates the robot autonomously navigating the predefined waypoints in Gazebo Harmonic, showing the robot's movement and interaction with the environment.

- **Visualization**: A graph (`visualizations/waypoint_path.png`) plots the robot’s position (x, y coordinates) against timestamps, generated by `visualizations/plot_waypoints.py` using ROS bag data. The plot confirms the robot’s path through waypoints `(-6.25, 0.0)`, `(0.0, 3.25)`, `(6.25, 0.0)`, and `(0.0, 0.0)`.

- **Future Goal**: Implement a buffer zone around waypoint targets (e.g., 0.5m radius) in the `waypoint_runner` node to consider goals reached when the robot is within the buffer, preventing excessive adjustments to achieve exact positioning and improving navigation efficiency.
